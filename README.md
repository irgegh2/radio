# NEXUS RADIO

Первый интерактивный frontend-прототип онлайн-радиостанции NEXUS RADIO, собранный по утверждённому визуальному макету.

## Что уже есть

- адаптивная тёмная главная страница;
- live-плеер с Play/Pause и громкостью;
- animated waveform;
- текущий трек и жанровые теги;
- блок «Сейчас в эфире»;
- «Далее в эфире»;
- дневная программа;
- история треков;
- карточки шоу;
- CTA «Написать в эфир»;
- мобильная версия.

## Локальный запуск

Проект не требует сборщика и зависимостей.

### Вариант 1 — Python

```bash
python -m http.server 5173
```

После запуска открыть:

```text
http://localhost:5173
```

### Вариант 2 — Node.js

```bash
npx serve . -l 5173
```

### Самый простой вариант

Можно открыть `index.html` двойным кликом. Для дальнейшей разработки лучше использовать локальный HTTP-сервер.

## Структура

- `index.html` — разметка;
- `styles.css` — весь UI и responsive;
- `app.js` — интерактивность плеера и элементов интерфейса.
